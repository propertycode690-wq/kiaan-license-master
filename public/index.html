Client API Reference

Endpoints called by your product backends to activate & verify domains.

POST /api/license/activate

Called by the client application on live server domain activation:

curl -X POST http://localhost:7000/api/license/activate \
  -H "Content-Type: application/json" \
  -d '{"product": "biotrack-pro", "key": "#104529", "domain": "clienthrm.com", "licenseType": "REGULAR"}'
POST /api/license/verify

Periodic heartbeat verification from active instances:

curl -X POST http://localhost:7000/api/license/verify \
  -H "Content-Type: application/json" \
  -d '{"product": "biotrack-pro", "key": "#104529", "domain": "clienthrm.com"}'
